# Abhinay Malyala Portfolio

A single-page personal portfolio for GitHub Pages.

## Publish on GitHub Pages

1. Create a public repository named exactly:
   `TheMalyala.github.io`
2. Upload `index.html`, `style.css`, and `script.js`.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save.
7. Your site will be available at:
   `https://themalayala.github.io/`

Replace any placeholder certification details and verify the LinkedIn URL before publishing.
